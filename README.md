# 🌌 Heinn Htet Zan | 5D Data & AI Portfolio

An immersive, intelligent digital portfolio highlighting the intersection of Data Science, AI, and Software Engineering. Built with modern React, Three.js, and Framer Motion.

## 🚀 Features

* **Dimension 1 — Content:** Complete transition from a standard software engineering portfolio to a premium Data & AI professional identity.
* **Dimension 2 — Motion:** Smooth scroll choreography and interactions powered by Framer Motion.
* **Dimension 3 — Depth:** Glass surfaces, spatial compositions, and 3D environment effects.
* **Dimension 4 — Data:** Interactive Technology Ecosystem mapping data flow across different skill domains.
* **Dimension 5 — Intelligence:** Dynamic GitHub API integration prioritizing AI, Data, and Machine Learning repositories.

## 🛠️ Technology Stack

* **Frontend:** React 18, TypeScript, Vite
* **Styling:** Tailwind CSS (Custom dark-first theme)
* **3D & Animation:** Three.js, React Three Fiber, Framer Motion
* **Icons:** Lucide React

## 💻 Local Development

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

## 🐳 Docker Deployment (Render, Railway, etc.)

This repository includes a `Dockerfile` optimized for static site deployment using Nginx. 

1. **Build the Docker image:**
   ```bash
   docker build -t 5d-portfolio .
   ```

2. **Run the container locally:**
   ```bash
   docker run -p 8080:80 5d-portfolio
   ```
   *The application will be available at `http://localhost:8080`*
